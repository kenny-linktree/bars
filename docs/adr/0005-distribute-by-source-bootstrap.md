# Distribute by cloning and building on each Mac

People install Bars by downloading and running a bootstrap script, as shown in the [README](../../README.md#install). The download must finish successfully before execution. The script clones the repository into `~/Library/Application Support/Bars/src`, builds the app and widget with Apple's Command Line Tools and runs the installer. No prebuilt binary is shipped. Bars uses ad-hoc signing rather than a Developer ID identity, as described in [ADR 0004](0004-publish-one-file-for-the-personal-widget.md). A locally compiled app normally has no download quarantine attribute, but local security policy can still prevent execution.

The future alternative is a Developer ID signed, notarized and stapled release. That requires a paid Apple Developer Program membership and a signing and notarization step for every release. It would allow a downloadable app without the Command Line Tools. It would also allow an authorized App Group instead of the single-file sandbox exception in ADR 0004. Revisit this decision if Bars spreads beyond people who are comfortable running a build script, or if a Developer ID becomes available.

Consequences: every Mac needs the Command Line Tools, about a minute of build time and Git access to the repository. The repository and branch are the trust boundary, because each Mac builds whatever it fetched. Updating means running the bootstrap again; it fetches and hard-resets the clone to the branch. The collector must run on the Command Line Tools' Python, 3.9.6 in the verified Command Line Tools installation, because Homebrew is not required. The collector therefore supports Python 3.9 or later and uses no newer standard-library features, and `tomllib` is replaced by a small reader for the Devin credential file. Each build has a new ad-hoc signature. Keychain reads go through `/usr/bin/security`, so earlier Keychain access decisions still apply after a rebuild. The installer detects which providers have local logins and disables the rest, so people who use only some providers see no errors for the others.
